# Ebenezer Comprehensive Pre-Primary and Secondary School

A static school website for Ebenezer Comprehensive Pre-Primary and Secondary School in Kabala, Koinadugu District, Sierra Leone.

## School information

- **Location:** Bumban Road, off Fullah Town, Kabala, Koinadugu District, Sierra Leone
- **Educational structure:** Nursery 1–3, Class 1–6, JSS 1–3 and SSS 1–3
- **Contact details:** Official phone number, email address and social links are intentionally marked for confirmation.

## Running the site

Open `index.html` in a browser or serve the repository with any static file server. The existing HTML, CSS and JavaScript structure has been retained.

## Content status

The page uses the repository's original layout and styling. Existing images are labelled as placeholders until approved Ebenezer photographs are supplied. Admissions payment, PIN generation and application submission are not implemented in this phase.
